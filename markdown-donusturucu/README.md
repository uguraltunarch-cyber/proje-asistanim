# Markdown Dönüştürücü

PDF, Word, Excel, PowerPoint ve HTML dosyalarını AnythingLLM gibi yapay zeka araçlarına uygun Markdown (.md) metnine çevirir.

## 1. Tarayıcı sürümü (kurulum yok)
`index.html` dosyasını indirip çift tıklayın; Chrome/Edge'de açılır. Dosyalar bilgisayardan çıkmaz. İnternet bağlantısı gerekir (okuyucu kütüphaneler açılışta yüklenir).

## 2. Masaüstü (.exe) sürümü
`MarkItDown_Exe_Olusturucu.zip` dosyasını indirip çıkarın, `ExeYap.bat` dosyasını çalıştırın. Bir kerelik Python (3.10–3.13) gerekir; sonunda tek bir `MarkItDown.exe` oluşur.

Not: Taranmış PDF'lerde (sayfaları fotoğraf olan) metin olmadığı için çıktı boş gelir.
